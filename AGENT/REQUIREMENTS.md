# Business Requirements Summary

> Full detailed specs are in `docs/Business Requirements/`. This file is a quick reference.

## Company Overview

**NovaTech Solutions Ltd.** — Bangladesh-based software development and IT consulting company. Target: 20+ clients, 100+ employees.

## Full Scope

| Area | Key Features |
|------|-------------|
| **CRM** | Lead → Meeting → Proposal → Quotation → Negotiation → Sales Order → Project → Invoice → Payment → Delivery |
| **Sales** | Quotation management, PDF export, auto Sales Order creation |
| **Projects** | Workspace, milestones, tasks, time tracking, budget tracking |
| **Task Management** | Checklists, comments, attachments, dependencies |
| **Time Tracking** | Manual, timer, weekly timesheet with approval |
| **HR** | Employee, attendance (5 methods), leave (5 types), payroll, onboarding/exit |
| **Finance** | Invoices, bills, payments, journal entries, P&L, cash flow |
| **AMC** | Auto-invoicing for recurring maintenance contracts |
| **Helpdesk** | Client portal tickets with SLA reporting |
| **Client Portal** | Projects, invoices, payments, tickets, documents |
| **Notifications** | Email + in-app for all events |
| **Dashboards** | Management, Sales, Project, HR, Finance, Support |

## HR Module Quick Reference

| Feature | Details |
|---------|---------|
| Attendance methods | Biometric, Mobile GPS, Web, Manual, Work From Home |
| Leave types | Casual, Sick, Earned, Unpaid, Special |
| Holiday calendar | Per-branch |
| Payroll | Monthly generation, salary slips |
| Reports | 17+ report types |

## Project Module Quick Reference

| Feature | Details |
|---------|---------|
| Task workflow | Open → In Progress → In Review → Rework → Completed |
| Time tracking | Manual, timer, weekly timesheet |
| Budget | Category-level cost tracking |
| Progress | Project/milestone/task level tracking |
| Closure | Checklist-based project closure |

## Implementation Priority

Based on business needs, suggested order:

1. **Phase 1**: HR (employee, attendance, leave, payroll)
2. **Phase 2**: CRM + Sales (lead management, quotations)
3. **Phase 3**: Projects + Time Tracking
4. **Phase 4**: Finance + Invoicing
5. **Phase 5**: Helpdesk + Client Portal
6. **Phase 6**: Dashboards + Reports
